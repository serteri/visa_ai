### post2: A code is not enough

A job title and an occupation code do not establish a migration outcome.

For IT roles, ACS publishes descriptions for Developer Programmer 261312 and Software Engineer 261313. The useful research question is how the published descriptions relate to the work someone actually does—not which label sounds closest.

LogiVisa links occupation research to the original assessment guidance, then to tools for the next questions. It provides information, not a personal assessment.
