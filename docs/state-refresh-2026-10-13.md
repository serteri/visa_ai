## Assumptions

1. NT's long status text cannot be an enum value (the admin dropdown, API validation and scoring all use the fixed list). NT uses `Suspended / Closed`, which scores as closed and keeps NT out of the open count; the exact wording is the first sentence of the note / AI summary / key facts and of the JSON `programWindow` and `specialConditions`.
2. SA is `Suspended / Closed`, not "Check official page": SA published a closure and a "resumes when 2026-27 commences" statement; it has not said 2026-27 has started. Change it in one place if you read the site differently.
3. WA is `Check official page` because nothing on the site says whether 2026-27 invitations are running.
4. `src/data/state-sponsorship.json` (the occupation demand heat-map) now shows NSW, VIC, SA and NT as `Closed` so it no longer contradicts the rules. WA, ACT, TAS, QLD unchanged there.
5. Facts kept from earlier documents (not contradicted, not re-fetched) are labelled as 2025-26 or earlier settings in the text.
6. 2025-26 narrative files that the new snapshots replace were moved to `<STATE>/_archive/` (ACT, NSW 190 and 491, QLD, SA state nomination / 190 / 491, WA program PDF). Files that were not replaced stay in place: the occupation lists (xlsx), WA invitation chart / ranking / trade-profile files, NT and TAS PDFs (until you save the new ones), business and employer documents.
7. The old index chunks of the archived files are still in the vector index; they are not removed by this run.
